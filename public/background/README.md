# Background Music

Put custom background music files in this folder, then run:

```bash
npm run build:background
```

Supported formats: `.mp3`, `.wav`, `.ogg`, `.m4a`.

The app loads `manifest.json` at runtime. Static hosting such as GitHub Pages cannot automatically list folder contents, so the manifest must be updated after adding or removing files.

Only add music that you have the right to redistribute in this repository.
